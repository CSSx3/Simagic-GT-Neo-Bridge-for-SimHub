# Changelog

## 0.2.2

- Translate the settings screen, device labels, status messages and error messages into English.
- Update plugin metadata to describe the native wheelbase transport.
- Add standalone English build, installation, troubleshooting and release documentation.
- Allow a custom SimHub path in the test script and runner.
- Retain the 0.2.1 transport, LED mapping, plugin identity and existing settings.

## 0.2.1

- Increase native heartbeat tolerance from 1500 ms to 5000 ms.
- Reduce reconnect interval from 5 seconds to 1 second.
- Restrict transport replacement to the original GT Neo device type.
- Preserve driver ownership during duplicate SDK initialization.

## 0.2.0

- Attach SimHub's wheelbase LED driver to the existing Simagic GT Neo device.
- Preserve existing LED profiles, brightness and car overrides.

## 0.1.x

- Prototype the legacy SimPro API transport with saved light configurations and verified recovery.
